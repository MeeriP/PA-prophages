# Prophage Analysis Pipeline

## Overview

This repository contains the scripts used for prophage identification, quality control, clustering, taxonomic annotation, antimicrobial resistance gene detection, virulence factor detection, defense system identification, CRISPR analyses, and secondary metabolite analyses described in Diverse prophage populations are associated with phage defense repertoire in Pseudomonas aeruginosa cystic fibrosis isolates.

## Workflow Overview

The analysis pipeline consists of the following steps:

1. Prophage identification using VirSorter2
2. Quality assessment using CheckV
3. Clustering of viral genomes based on ANI
4. Taxonomic annotation using geNomad
5. Antimicrobial resistance gene detection using RGI/CARD
6. Virulence factor screening using Abricate/VFDB
7. Defense system identification using DefenseFinder
8. Anti-defense system identification using DefenseFinder
9. CRISPR array detection with CRISPRdetect by PADLOC
10. CRISPR spacer clustering with CD-HIT
11. Spacer matching against representative prophages with BLAST
12. Secondary metabolite biosynthetic gene cluster detection using antiSMASH. The resulting GenBank files were subsequently parsed using the script gbk_protocluster_parse_1.4.py generated by https://github.com/dalofa/gbk_protocluster_parse/tree/main
